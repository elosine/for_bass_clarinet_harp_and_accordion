Slides up and down
Finale
To use this feature you need to create five expressions:
1. An (invisible) expression with the playback defintion  CC#0 = 122 (slide mode on)→
2. An (invisible) expression with the data dump  3 144 32 0 (slide down function key on) →
3. An (invisible) expression with the data dump  3 128 32 0 (slide down function key off) →
4. An (invisible) expression with the data dump  3 144 33 0 (slide up function key on) →
5. An (invisible) expression with the data dump  3 128 33 0 (slide up function key off) →
For fine adjustment of the slide sound the position of the slide expression is important.
You can do this by right clicking the handle and select „Edit Expression Assignment...“. 
Then use the value for the „Aligment Point“ to adjust the start position of the slide.

Sibelius
Please use the following text commands to control slides in your score:
1. ~C0,122 (slide mode on)
2. ~N32,64 (slide down function key on)
3. ~O32,0 (slide down function key off)
4. ~N33,64 (slide up function key on)
5. ~O33,0 (slide up function key off)
To make fine adjustments move the text commands (N33 / N32) slightly right or left.
