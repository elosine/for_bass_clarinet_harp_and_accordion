# Timbre Vocabulary — velocity bands per virtual instrument

> **What this is:** the catalog of available sounds inside each sample instrument,
> organized as **velocity bands** — a standardized band key (`v1`…`vN`, soft → loud,
> count varies per instrument) + the composer's qualitative comments.
>
> **D7 discipline:** these are RENDERING-side facts about the samples. At notation
> time the composer re-evaluates: a band's musical identity may translate to
> dynamics, or to technique/position (près de la table, etc.), or live somewhere
> else entirely. This file codifies the libraries, not the piece.
>
> Ranges are provisional: samples differ per note. Bands are defined globally first;
> per-note / per-tessitura refinements get added when composing reveals them.
