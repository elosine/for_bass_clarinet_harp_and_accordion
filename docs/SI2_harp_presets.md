## Patch UI controls observed (Harp Ordinario loaded — S2.2 schema fodder)

- **Play Mode:** Polyphonic (dropdown; Range 5 / Time 50 fields greyed → other modes exist)
- **Amplitude:** Attack 0.00 · Release 7.00
- **Dynamic:** Amount 0.80 + response-curve display
- **Expression:** source dropdown (showing *Velocity*) · **Constant** checkbox + **Value** field (60) — fixes velocity response; useful as a probing tool for the velocity→timbre map · Expand Range checkbox
- **Timbre:** Color knob
- **Equalizer:** Lo/Mid/Hi (toggleable)
- **IR Reverb:** preset (TC Large Hall) + Dry/Wet — for the rack, likely OFF/dry (room sound belongs to the demo mix, not the identity)
- Keyboard strip shows playable range highlighted; extremes greyed
